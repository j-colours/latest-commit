# Latest Commit

Command line tool that simply grabs the most recent commit from the log (includes information and the 1-2 line commit message).

# Instructions

To run simply install it first where it will copy the tool onto your systems path. Keep in mind this works currently for Unix Systems only so on Windows
run it using `wsl`. ***MUST HAVE SUDO PERMISSIONS***. Once the repo is cloned onto the computer you can install the script using the `install` script
and if you want to `update` to the latest version, simply `git pull` in the cloned repo and then run the `remove` then `install` script or use the `reinstall` script to run both in one command. Another way to update is to utilize `lcommit -u | lcommit --update` to update to the most recent files which is much easier considering you can destroy the cloned repo if you utilize this method.
